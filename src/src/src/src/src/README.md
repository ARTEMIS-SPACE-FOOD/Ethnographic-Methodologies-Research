# Artemis II Food Ethnography Demonstration

## Overview
This project implements a reproducible anthropological analytics pipeline for CGMacros spaceflight nutrition data.

It models food as:
- ritual behavior
- psychological regulation system
- social coordination mechanism
- biocultural adaptation signal

## Data Source
CGMacros dataset:
https://physionet.org/content/cgmacros/1.0.0/

Place dataset in:
data/cgmacros/

## Run

```bash
pip install -r requirements.txt
python run_demo.py
```
